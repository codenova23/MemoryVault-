# Memory Vault

Open `index.html` directly in a browser, or publish it to GitHub Pages. The complete website is contained in that one file; it needs no build step, package manager, server, or API key.

Memories and capsules are saved in the browser's localStorage. This demo does not provide encryption, accounts, or remote backups. Sample cover photos and web fonts are loaded from external services; uploaded photos are compressed in the browser before being stored locally.
